# Consigna

Con un botón y un led guardar una secuencia de prendidos y apagados en un vector de la siguiente manera: se prende el led indicando al usuario que puede tocar el botón – el usuario puede mantener apretado o no el botón en ese momento hasta que se apague el led – una vez que se apague se guarda el dato del botón en un vector – y vuelve a prender el led para que el usuario elija si apretar o no el botón y continuar la secuencia 5 veces -  una vez que se guardan los 5 datos se muestra por la consola el vector, se limpia el vector y se vuelve a empezar.
